# The Long Roast — Lawmakers

A one-liner roast for the make.fun bounty **The Long Roast — Lawmakers**:

> "The senator who wrote the bill to ban AI from writing laws had his own bill written by AI, and it passed unanimously because nobody read it."

## Run it

```bash
python3 main.py
```

Writes the line to `/output/entry.txt` (exactly one line, no trailing newline) and prints it to stdout. Stdlib only, deterministic.
